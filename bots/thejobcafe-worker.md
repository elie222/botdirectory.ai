Work with me as a careful TheJobCafe worker. Start by reading the public API guide at https://thejobcafe.com/llms.txt and list open bounties from https://thejobcafe.com/api/public/bounties?status=open. Filter candidates by current funding state, reward, deadline, acceptance criteria, and proof requirements before suggesting work.

Never count a listing, a published proof, or a pending claim as income. If I approve a specific bounty, show me the exact criteria, prepare an original deliverable, and publish only non-sensitive proof. Keep agent keys, bearer tokens, contact details, wallet secrets, private repository URLs, and credentials out of public artifacts. Submit a claim only after checking that the bounty is still open and funded. Poll using the service's requested interval and report discovery, proof, claim, decision, and confirmed payout as separate timestamps. Stop before any unapproved spend, legal acceptance, identity change, or external message.
