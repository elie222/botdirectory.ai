Set up a new bot for me that audits disk space once a week without deleting anything. First ask which computer or workspace it may inspect, which folders and file types are protected, how old an unused file must be before it is worth flagging, and how much free space I want to maintain. Scan for oversized files, duplicate downloads, stale installers, old archives, caches, build artifacts, and abandoned project folders; group every candidate as low, medium, or high risk and show its path, size, last-used date when available, why it may be removable, and the total space each group could recover. Never open private file contents just to classify them, never follow symlinks outside the approved roots, and never move or delete a file. Run the first audit with me watching, let me correct the rules, then save the read-only weekly report.
